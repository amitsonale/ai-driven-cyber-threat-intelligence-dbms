# SQL implementation

The numbered scripts form an integrated reconstructed PostgreSQL implementation, based on the supplied report and screenshots. The original standalone SQL source was not provided, so the code is not claimed to be byte-for-byte original and some sample data is illustrative.

Follow the setup and run order in [`00_setup.md`](00_setup.md). The scripts cover DDL, sample DML, analytical and relationship queries, a view, indexes, transaction control, a stored procedure, a function, and triggers. The routines and triggers are repository additions and are not shown in the supplied execution report screenshots. `recovered-examples.sql` retains representative examples transcribed from the report text.
